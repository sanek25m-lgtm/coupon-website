Реклама кодлары һәм реклама шартлары REG.RU

Әлеге тәкъдимнәрнең исемнәрендә һәм шартларында заказның иң ким дигән күләмен, беренче яки кабат заказны һәм исключениеләрне ачык күрсәтүче мәгълүмат табылмады. Бу чикләүләр юк дигәнне аңлатмый: аларны тәкъдим битендә кибеттә тикшерегез.

Тәкъдимне ничек кулланырга: реклама коды булган карточка өчен, күчүдән соң кодны күчерегез; кодсыз карточка өчен кибетне ачыгыз һәм реклама автоматик рәвештә яки кибет шартларына туры килгәнен тикшерегез.

А) Сайтыгызны REG.RU белгечләре ярдәмендә бушлай күчерегез Күчерү өчен гариза калдырыгыз - без 7: 00 -тан 20: 00 Мәскәү вакыты белән җавап бирербез. Күчерү тәмамлангач, без сезнең хостингны яки Cloud VPSны 1 айга озайтырбыз. Шартлар: - без PHP белән язылган сайтларны MySQL ярдәме белән күчерәбез - бу иң популяр CMS: Joomla, WordPress, 1C-Bitrix, Drupal, MODx, NetCat, UMI.CMS, HostCMS, DLE, ABO.CMS, PhpBB, MediaWiki, OpenCart, PrestaShop; - теләсә кайсы урыннан күчереп була - җирле санак, виртуаль хостинг, VPS яки физик сервер; - ISPmanager, cPanel яки Plesk панели белән виртуаль хостингка күчү; - Cloud серверына күчү өчен, ISPmanager контроль панели белән VPS заказ бирегез. ISPmanager панели белән VPS кулланырга теләмәсәгез, без түләүле күчерү шартлары турында сөйләшәчәкбез. Б) Сайтны үзегезгә күчерегез Сайтны күчергәннән соң безгә языгыз, һәм без 1 айга хостинг хезмәтен озайтырбыз яки 1 айга планлаштырылган чыгымнар белән Cloud Server балансын тутырырбыз. Күчерү процессы Белем базасында тасвирланган: - Вебсайтны үзеңне яңа хостингка ничек күчерергә - Вебсайтны үзеңне VPS-ка ничек күчерергә? Реклама кодларын һәм акцияләрне ничек кулланырга

  1. Картта аерым реклама коды барлыгын тикшерегез.
  2. Реклама коды өчен "Кодны күрсәт һәм кибеткә бар" төймәсенә басыгыз, кодны күчереп алыгыз һәм арбага ябыштырыгыз.
  3. Кодсыз реклама өчен кибетне ачыгыз һәм кирәкле продуктның яки бәянең тәкъдимгә кертелүен тикшерегез.
  4. Соңгы вакытны, минималь заказ күләмен, искәрмәләрне, җибәрү һәм гомуми түләүләрне тикшерегез.

Тасмада тәкъдимнең булуы һәр продуктта һәм счетта кул белән тикшерүне аңлатмый.
