Қате туралы хабарлау

Хабарламаны GitHub жобасы репозиторийіне жіберуге болады. GitHub тіркелгісі қажет болады; хабарлама ашық болады. Тапсырыс нөмірлерін, телефондарды, токендерді және басқа да жеке мәліметтерді қоспаңыз.

GitHub-тегі хабарламаны жасау

Қате шыққан кезде дүкенді, купон ID және шарттарды көрсету қажет. Жауап беру мерзімі кепілдендірілмеген.

Шарттардың аудармасы автоматты түрде жасалды. Шарттарды дүкеннің сайтында тексеріңіз.
