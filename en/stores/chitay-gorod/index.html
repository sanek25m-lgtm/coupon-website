How to use promotional codes and promotions

  1. Check if there is a separate promotional code on the card.
  2. For a promotional code, click “Show code and go to store”, copy the code and paste it into the cart.
  3. For a promotion without a code, open the store and check that the desired product or rate is included in the offer.
  4. Check the deadline, minimum order amount, exceptions, delivery and total payment.

The presence of an offer in the feed does not mean manual verification on each product and account.

Условия покупки

Вход перед оформлением

Заказ оформляют из профиля: вход подтверждается кодом на телефон. Для регистрации FAQ указывает российский номер телефона.

Цена и дата доставки

Доставка в магазины сети описана как бесплатная; для других способов стоимость рассчитывается при оформлении. Ориентировочная дата появляется после выбора адреса и способа, затем видна в разделе заказов.

Источник: Читай-город: вопросы об оформлении и получении

Оплата при получении

У перевозчиков способы оплаты различаются. Сайт показывает доступные варианты для выбранной службы; условия магазинов сети нельзя автоматически переносить на любой пункт выдачи.

Как оформить заказ и проверить предложение

Как оформить и проверить книжный заказ

  1. Войдите в профиль на официальном сайте по своему номеру телефона и коду.
  2. Добавьте выбранные товары в корзину.
  3. Перейдите к оформлению и заполните сведения получателя.
  4. Выберите получение, проверьте стоимость и приблизительную дату.
  5. Сохраните номер заказа и дождитесь уведомления о поступлении в магазин.
