How to use promotional codes and promotions

  1. Check if there is a separate promotional code on the card.

Как оформить заказ и проверить предложение

Как обратиться при задержке посылки

  1. Откройте свои заказы.
  2. Выберите нужную покупку и проверьте дату гарантии.
  3. Если гарантия открыта, а посылка не получена, отметьте отсутствие заказа.
  4. Укажите верную почту для ответа поддержки.
  5. Если отслеживание недавно обновлялось в России, сначала свяжитесь с поддержкой напрямую.
